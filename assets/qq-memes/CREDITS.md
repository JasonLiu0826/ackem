# 内置表情包素材说明

本目录是随 Ackem 分发的 QQ 内置表情包（`cute-2026` 包），共 **70 张**。

## 版权与来源

素材均来自公开网络传播的热门梗图 / 表情包，**版权归各原作者所有**，
仅随项目用于个人非商业场景，与 `packs/chinesebqb` 的处理方式一致。
如原作者要求下架，删除对应文件即可，无需改动代码。

部分图片保留了原发布平台的角标，这是表情包在网络传播中的常态；
介意的话把自己的同名图放进 `{dataRoot}/qq-memes/<情绪>/` 即可覆盖。

图片通过公开图片搜索采集，`manifest.json` 记录了每张图的原始地址，便于溯源。

## 目录结构

目录名就是情绪标签，`src/main/channels/qq/memes.ts` 按目录名归类：

| 目录 | 情绪含义 | 张数 |
| --- | --- | --- |
| `love/` | 亲密、撒娇、亲亲抱抱 | 23 |
| `shy/` | 害羞、娇羞、小声撒娇 | 12 |
| `warm/` | 温柔、安慰、贴贴陪伴 | 10 |
| `playful/` | 开心、玩闹、沙雕 | 7 |
| `tease/` | 逗、傲娇、挑衅 | 3 |
| `hype/` | 兴奋、冲、起飞 | 3 |

| `annoyed/` | 生气、凶、不满 | 1 |
| `cold/` | 无语、冷漠、白眼 | 3 |
