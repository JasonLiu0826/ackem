# 感知、附件与真实任务

[English](perception-layer.md)

Ackem 的桌宠、媒体、语音、附件与扩展感知分布在不同模块；不要假定存在一套全局感知授权或实时屏幕视觉。

| 输入或能力 | 当前边界 |
|---|---|
| 用户图片 | 作为实际图片输入；模型支持与读取结果决定能否理解 |
| 文件/目录附件 | 按实际捕获、读取与 work 工具结果处理 |
| 视频 | 可提供实际抽样画面，不代表完整观看或读取全部音轨 |
| 语音 | 依赖具体本机或外部服务配置 |
| 桌宠 / Live2D | 展示与交互，不等于获取整个桌面视觉 |
| 前台、剪贴板、截图等插件 | 必须核对 manifest、注册实现和 active 状态；占位条目不代表可运行 |
| AckemCode 的系统/文件检查 | 在任务授权下通过工具执行，不来自旧电脑助手 |

截图、剪贴板等命名条目可存在 stub 或 deprecated 实现，不能仅凭目录名宣称已具备能力。内核可用的 MCP / 外部工具也需单独配置。

插件权限与工作任务权限分别管理。用户提供了附件，不意味着可以描述未读取的画面或内容；模型输出不是读取证据。
