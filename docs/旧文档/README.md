# 旧文档归档

[当前项目说明](../../README.md) · [当前文档导航](../README.md) · [当前架构](../architecture.zh.md)

本文件夹集中保存已被新版替代的公开说明、旧架构长文、历史发布材料，以及本地设计与审计记录。归档内容用于追溯，不能作为当前功能、路由、权限或接口的依据。

共保存 **143 份公开历史稿、48 份本地记录**。当前阅读入口为六类主文档；本目录本身的索引不计入历史稿数。

## 归档范围

- **首轮公开文档：78 份**，位于 [公开文档](公开文档)。更新前版本取自提交 `eee23f439536a6d9d684115ae1f3a1a683f6316f`；其中 10 份旧架构长文保留了归档前已经整理的图表，3 份历史发布材料从原目录移入。
- **六类收敛前文档：65 份**，位于 [收敛前文档](./收敛前文档/)。包含移出的 63 份分散指南及收敛前中英文 README 副本；当前完整说明已合并到六类主文档。
- **本地记录：48 份**，位于 `本地记录/`。原本受 Git 忽略的设计稿与审计记录继续保持本地保存。
- 公开文档沿用原仓库目录结构；相对链接已调整到归档内对应文件或仍有效的当前源码与资源。旧稿中未随源码收录的内部引用已明确标注。
- 许可证、行为准则、人格语料以及仍适用的模块协议继续保留在原位置。
